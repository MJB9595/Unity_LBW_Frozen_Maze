
# 🧊 Unity LBW — Frozen Maze

> **벽화 변환(Wall Merge)** 이동 메카닉을 Unity로 구현한 HDRP 프로토타입 프로젝트입니다.

---

## 📖 프로젝트 소개

**LBW (Link Between Walls)** 는 *젤다의 전설: 신들의 트라이포스 2* 에서 링크가 벽에 그림처럼 달라붙어 이동하는 **벽화 변환 기믹**에서 영감을 받아 제작된 Unity 6 프로토타입입니다.

플레이어 캐릭터가 벽에 납작하게 합체되어 벽면을 자유롭게 이동하고, 코너를 돌며, 좁은 틈새를 통과하는 메카닉을 HDRP 고품질 렌더링과 다양한 연출 이펙트를 곁들여 구현했습니다. 배경은 얼어붙은 미로(Frozen Maze)를 무대로 합니다.

---

## 🎮 핵심 메카닉 — 벽화 변환 (Wall Merge)

이 프로젝트의 핵심은 **Wall Merge 시스템**입니다:

1. **합체 (Merge)**: 벽을 바라보는 상태에서 `Space`를 누르면 캐릭터가 벽면에 납작하게 달라붙습니다. 플레이어 위치에서 가장 가까운 코너 사이 지점에 데칼 프로젝터 형태로 배치됩니다.
2. **이동 (Move)**: `A / D` 또는 `← / →` 키로 벽면을 따라 좌우로 이동합니다.
3. **코너 회전 (Corner Rotation)**: 벽의 꺾이는 지점에 가까워지면 표면 법선(Normal) 벡터의 직선 교점으로 피벗을 계산해 캐릭터가 자연스럽게 코너를 돌아 넘어갑니다.
4. **틈새 통과 (Gap Transition)**: `GapTrigger` 트리거 존이 설치된 좁은 통로를 통과할 때 포탈 연출이 발동합니다 — 데칼이 찌그러지며 사라졌다가, DoF·줌 포스트 프로세싱과 파티클 이펙트와 함께 반대편에서 복구됩니다.
5. **탈출 (Exit)**: 합체 상태에서 다시 `Space`를 누르면 3D 공간으로 복귀합니다.

## 🏗️ 기술 구조

### 스크립트

| 스크립트 | 역할 |
|---|---|
| `WallMerge.cs` | 합체 핵심 로직 — 플레이어↔벽 전환, 데칼 레이어 관리, 포스트 프로세싱, 카메라 전환 |
| `ProjectorMovement.cs` | 벽면 데칼 아바타 제어 — 이동, 코너 회전, 틈새 감지, 포탈 이펙트 |
| `RaySearch.cs` | 재귀 레이캐스트로 벽면을 탐색해 코너 포인트와 표면 법선을 수집 |
| `GapTrigger.cs` | 좁은 통로에 배치하는 마커 컴포넌트 — 포탈 연출 트리거 식별용 |

### 주요 시스템 상세

**벽면 탐색 (RaySearch)**
재귀 레이캐스트 알고리즘이 벽 표면을 따라 걸어가며 `MeshPoint` 구조체(위치 + 법선) 목록을 구축합니다. 법선이 크게 변하는 지점을 코너로 인식해 코너 포인트 리스트를 별도로 관리합니다.

**코너 피벗 계산 (ProjectorMovement)**
코너 도달 시 두 엣지 참조 벡터의 **직선-직선 교점(Line-Line Intersection)** 으로 정밀한 피벗 위치를 계산합니다. 어떤 각도의 코너도 클리핑 없이 부드럽게 회전할 수 있습니다.

**데칼 레이어 격리 (WallMerge)**
현재 플레이어가 합체한 벽에만 `DecalLayer` 렌더링 비트를 활성화합니다. 씬 시작 시 모든 벽에서 해당 레이어 비트를 제거하고, 이동 중 벽이 바뀌면 이전 벽은 복원, 새 벽에만 적용해 데칼이 엉뚱한 벽에 번지는 현상을 방지합니다.

**전환 이펙트**
- Cinemachine 카메라 블렌드 (`NormalCam` ↔ `WallCam`)
- DOTween 시퀀스를 이용한 스케일·위치 트랜지션
- 합체·틈새 통과 시 HDRP Post-Processing Volume (DoF, Zoom) 적용
- 월드 스페이스 파티클 시스템 (합체 진입·탈출 이펙트)
- 합체 지점에서 페이드인/아웃되는 프레임 쿼드

### 사용 패키지 및 에셋

- **Unity 6** + **HDRP** (High Definition Render Pipeline)
- **DOTween** — 애니메이션 & 트위닝
- **Cinemachine** — 카메라 블렌딩
- **Jammo Character** — 플레이어 캐릭터 리그 & 애니메이션
- **Unity Input System** — 키보드 / 게임패드 입력

## 🕹️ 조작 방법

| 키 | 동작 |
|---|---|
| `W A S D` / 방향키 | 캐릭터 이동 |
| `Space` | 벽 합체 / 탈출 |
| `A / D` (합체 중) | 벽면 좌우 이동 |
| `Left Shift` | 달리기 |
| `R` | 씬 재시작 |
| `Escape` | 게임 종료 |

## 🚀 시작하기

1. 레포지토리를 클론합니다.
2. **Unity 6** (HDRP 프로젝트)로 엽니다.
3. `Assets/Scenes/` 경로의 메인 씬을 엽니다.
4. **Play** 를 누르고 벽을 바라본 상태에서 `Space` 를 눌러 벽화 변환 메카닉을 체험해 보세요.

> ⚠️ 이 프로젝트는 **Unity 6** 과 **High Definition Render Pipeline** 패키지가 필요합니다.
> 플레이 전에 `Window > Package Manager` 에서 HDRP가 올바르게 설정되어 있는지 확인해 주세요.

---

## 💡 참고 사항

- `GapTrigger` 감지 범위는 기본 반경 **0.5m** 구체입니다. 포탈 연출이 너무 일찍 혹은 늦게 발동된다면 씬에서 트리거 콜라이더 크기를 조정하세요.
- 데칼 레이어 인덱스는 `WallMerge` 컴포넌트에서 설정 가능합니다 (기본값: 인덱스 1). 플레이어 데칼의 `DecalProjector` 레이어와 반드시 일치시켜야 합니다.
- `R` 키로 씬을 빠르게 재시작할 수 있습니다.
